# Koushil R Gowda | Portfolio
Live site: https://koushil24.github.io

## How to update (no design changes needed)
All content is in the `data/` folder. Edit text, save, and commit.
- New project: copy one `{ ... }` block in `data/projects.js`
- New job: copy one block in `data/experience.js`
- New skill: edit `data/skills.js`
- New certificate: put the JPG in `assets/certificates/` and add a line in `data/certificates.js`
- New resume: replace the PDF in `assets/resume/` (keep the same file name)
- Photo: `assets/images/koushil.jpg`
